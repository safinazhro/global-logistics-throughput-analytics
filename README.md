# Global Logistics Throughput & Labor Analytics Platform

An enterprise-grade data control tower dashboard designed to monitor logistics KPIs, detect warehouse constraints, and mitigate financial risks.

## Business Impact Summary
* **Bottleneck Mitigation:** Identifies labor allocation patterns that delay standard dry cargo processing beyond the optimal 2-hour threshold.
* **Risk Management:** Features an automated financial tracker for potential truck demurrage penalties.
* **Operational Insights:** Highlights resource efficiency drops in specialized cargo handling (Hazardous & Refrigerated).

## Tech Stack & Architecture
* **Language:** Python
* **Data Framework:** Pandas, NumPy
* **Interface Rendering:** Streamlit Framework
